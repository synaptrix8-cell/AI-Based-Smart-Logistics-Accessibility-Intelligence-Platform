# Workflows

Markdown SOPs (Standard Operating Procedures) that define **what** to do and **how**.

## Each Workflow Should Include

- **Objective** — What this workflow accomplishes
- **Required Inputs** — What's needed before starting
- **Tools Used** — Which scripts from `tools/` are called
- **Expected Outputs** — What success looks like
- **Edge Cases** — How to handle failures and unexpected behavior

## Rules

- Don't create or overwrite workflows without asking unless explicitly told to
- Update workflows when you discover better methods, constraints, or recurring issues
- Written in plain language — like briefing a teammate
